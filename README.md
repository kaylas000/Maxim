# Дело №12 · Максим Селиванов

Одностраничное дело: кодовая заставка (оранжевые буквы с искрами на глубоком синем)
и шесть листов — наряд, шаги сборки, реестр достижений, команда, быт, поздравление.

## Файлы

— `index.html` · разметка всех листов
— `styles.css` · токены палитры, зерно, типографика, заставка
— `main.js` · движок заставки (204 кадра при 60 fps, три пресета титра) и секвенция
  обложки: литеры «МОИ 12» прилетают по одной, линия прочерчивается, штамп прижимается
— `page.js` · липкая сцена шагов, фильтр реестра в пяти состояниях, форма поздравления

Ноль npm-зависимостей, сборка статическая: открыть `index.html` или отдать папку
любым хостингом. Заставка показывается один раз за сессию, пропускается кнопкой или
ESC и не играется при системной настройке «уменьшить движение»; без JavaScript дело
выглядит целиком, анимации только добавляют появление.

## Мобильные и анимационные проверки

Вёрстка правилась по списку 22 вьюпортов цеха: титр и заголовок пересчитаны по метрике
шрифта, реестр на телефоне становится стеком вместо таблицы, навигация — лентой с
прокруткой, тап-зоны ≥44px, поля ввода 16px, кегль нигде не ниже 12px, `:hover`
дублируется `:active`, учитаны `env(safe-area-inset-*)`. В телефоне-раскрытой
книжке и в ландшафте sizes считаются от высоты вьюпорта.

Тройной тап по экрану включает live-диагностику: ширина вьюпорта, наличие
горизонтального скролла, зоны тапа меньше 44px, состояние заставки и героя.
