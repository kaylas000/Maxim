# Дело №12 · Максим Селиванов

Одностраничное дело: кодовая заставка (оранжевые буквы с искрами на глубоком синем)
и шесть листов — наряд, шаги сборки, реестр достижений, команда, быт, поздравление.

## Файлы

— `index.html` · разметка всех листов
— `styles.css` · токены палитры, зерно, типографика, заставка
— `main.js` · движок заставки: 204 кадра при 60 fps, три пресета титра
— `page.js` · липкая сцена шагов, фильтр реестра, форма поздравления

Ноль npm-зависимостей, сборка статическая: открыть `index.html` или отдать папку
любым хостингом. Заставка показывается один раз за сессию, пропускается кнопкой или
ESC и не играется при системной настройке «уменьшить движение».

## Приватность

Адрес, школа, телефон и геометки не публикуются. Фотографии семьи заменены
диагональной штриховкой до согласия родителей.
